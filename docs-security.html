What we hold, where it lives, who can reach it, and what you can hand an auditor. Written to be usable as the first draft of a questionnaire answer.

What we store

  • Metadata always — execution IDs, timings, token counts, stage names, connection names, costs and decisions.
  • Payloads by policy — inputs and outputs are stored only if you enable it, and expire on the retention you set.
  • Credentials never in plaintext — integrations keep an encrypted refresh token; API keys are stored as hashes and shown once.
Redaction happens before the model call

With pii_redaction: true, emails, phone numbers, card and account numbers are masked in the payload before it reaches a model or is written to storage. The trace keeps the shape of the data, not its contents.

Access control

Three roles, least privilege by default:

Group membership drives checkpoint routing, so contract decisions follow the same groups your identity provider already maintains.

The evidence chain

Every human and worker action is appended with a hash of the previous entry. Entries cannot be edited or deleted, and a gap is detectable. Verification runs continuously and on demand from the Decision Record page.

  "action": "checkpoint.accepted",

Isolation

  • Workspaces are isolated at the data layer; a key can never read across them
  • Connection calls run in network-isolated workers with an egress allow-list
  • New connections can be forced through a sandbox worker on first use
  • Enterprise workspaces run execution workers inside their own VPC — payloads never leave the customer network

GDPR and data subject requests

  • DPA available for all paid plans; sub-processor list published
  • Erasure requests remove payloads and mask actor identifiers, while the evidence chain keeps the fact that an action happened
  • Export of all workspace data on request, in JSON and CSV
  • Retention is configurable down to 30 days for payloads; evidence retention is fixed at 400 days for integrity

Incident response

Security incidents are triaged within one hour, with customer notification inside 24 hours of confirmation. Status and post-mortems are published for anything affecting the control plane. Report a vulnerability from the contact page — we do not pursue good-faith researchers.

For the questionnaire

Enterprise workspaces get the SOC 2 report, the latest penetration test summary, the DPA and a completed CAIQ under NDA. Ask your account contact, or write to us and we will route it.
